== Description ==
Product Video Reels adds a configurable product-video field to WooCommerce and renders videos in horizontal, vertical or reels-style layouts.

== Installation ==
1. Upload the product-video-reels folder to /wp-content/plugins/
2. Activate the plugin.
3. Open WooCommerce > ویدئوی محصول.
4. Edit a product and add a video URL.
