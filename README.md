# ویدئوی محصول و ریلز

افزونه افزودن ویدئو به محصولات ووکامرس با پشتیبانی از ویدئوی افقی، عمودی و نمایش ریلز.

## ویژگی‌ها
- انتخاب ویدئو از کتابخانه رسانه وردپرس
- استفاده از لینک خارجی ویدئو
- حالت افقی و عمودی
- نمایش ریلز شبیه شبکه‌های اجتماعی
- تنظیم نمایش خودکار/بی‌صدا/لوپ
- رابط فارسی و مینیمال
- سازگار با WooCommerce
